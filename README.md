Este repositorio contiene la arquitectura frontend para **Café Rústico**. Es un sitio web moderno, responsivo y de alto rendimiento construido con JavaScript vanilla, CSS3 y HTML5. Diseñado bajo una **Arquitectura Comercial Multipágina**, presenta la identidad visual, un menú interactivo, sistema de reservas y reseñas dinámicas de una cafetería contemporánea, priorizando una experiencia de usuario (UX) premium. Node.js se utiliza exclusivamente como entorno de desarrollo local mediante live-server para optimizar el flujo de trabajo.

## ✨ Features

* **Experiencia UI/UX Premium:** Microinteracciones avanzadas, animaciones de entrada (fade-in/slide-up) al hacer scroll y transiciones de estado ultra fluidas que elevan la percepción de la marca.
* **Dynamic UI & Navegación Fluida:** Navegación optimizada con desplazamiento suave (smooth scroll) entre secciones, indicadores visuales de interacción y filtrado de productos por categoría utilizando lógica modular en JavaScript.
* **Sistema de Reseñas Interactivo:** Formulario de comunidad dinámico con feedback visual en tiempo real (animación de calificación por estrellas) y validación frontend integrada sin necesidad de recargar la página.
* **Modern & Rustic Design:** Identidad visual construida sobre una paleta de colores personalizada (Espresso, Canela, Latte) y tipografías distintivas para garantizar una estética artesanal y elegante.
* **Responsive Layout:** Estructura mobile-first utilizando CSS Grid, Flexbox y variables nativas para asegurar un rendimiento óptimo y adaptabilidad milimétrica en todos los dispositivos.

## 🛠 Technologies Used

* **Core Stack:** HTML5 Semántico, CSS3 (Animaciones y Custom Properties)
* **Languages:** JavaScript ES6+ (Vanilla, sin frameworks)
* **Development Environment:** Node.js (live-server, npm)
* **Design System:** Variables CSS nativas, tipografías Playfair Display y Lato.
