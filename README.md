Este repositorio contiene la arquitectura frontend para Café Rústico. Es un sitio web estático moderno y responsivo construido con JavaScript vanilla, CSS3 y HTML5 que presenta la identidad visual, el menú interactivo y la ubicación de una cafetería contemporánea. Node.js se utiliza exclusivamente como entorno de desarrollo local mediante live-server para optimizar el flujo de trabajo.

## Features

* **Dynamic UI Architecture:** Interfaz de usuario interactiva con filtrado de productos por categoría y mapas embebidos utilizando lógica modular en JavaScript.
* **Modern & Rustic Design:** Identidad visual construida sobre una paleta de colores personalizada (Espresso, Canela, Latte) y tipografías distintivas para garantizar una experiencia de usuario (UX) coherente.
* **Responsive Layout:** Estructura mobile-first utilizando CSS Grid, Flexbox y variables nativas para asegurar un rendimiento óptimo y adaptabilidad en todos los dispositivos.
* **Client-Side Validation:** Procesamiento de formularios de contacto con validación frontend integrada sin necesidad de recargar la página.

## Technologies Used

* **Core Stack:** HTML5 Semántico, CSS3
* **Languages:** JavaScript ES6+ (Vanilla, sin frameworks)
* **Development Environment:** Node.js (live-server)
* **Design System:** Variables CSS nativas, tipografías Playfair Display y Lato.
